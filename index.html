О проекте

Меньше времени на поиск, больше — на дело

Учебный планер — концепция простого инструмента для студентов. Он помогает собрать задания по разным предметам и не терять их среди сообщений и файлов.

Эта страница показывает идею проекта. Примеры задач на ней демонстрационные.
Возможности

Порядок начинается с малого

01 / ЗАДАЧИ

Единый список

Названия, предметы и сроки помогают увидеть всю учебную нагрузку.

02 / ФОКУС

Понятные статусы

Отмечайте, что запланировано, находится в работе или уже завершено.

03 / НАВИГАЦИЯ

Быстрый поиск

Находите нужную работу по названию и сосредоточьтесь на ближайшем деле.

Как использовать

Три шага к плану на неделю

01

Соберите задания

Запишите работы и укажите дисциплину и срок сдачи.

02

Выберите главное

Посмотрите на ближайшие даты и решите, с чего начать.

03

Отметьте результат

Обновляйте статус, чтобы видеть продвижение.

Для кого

Для тех, кто учится и планирует

Планер пригодится, если в расписании несколько дисциплин, задания приходят из разных источников, а сроки хочется держать перед глазами.

Вопросы

Как пользоваться планом?

Эта страница сохраняет мои задания?

Пока нет: это демонстрация идеи. Запишите задания в удобном для вас приложении или блокноте.

С чего начать?

Соберите ближайшие сроки, выберите одну небольшую задачу и выделите для неё время.

Идея проекта

Начните с одного списка

Соберите ближайшие задания в заметке и выберите одно, с которого начнёте сегодня.
